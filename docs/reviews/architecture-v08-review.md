## 근거

- 사용자 결정 R "하데스처럼 방 구조로" → 섞기: 방 = 짧은 생존(v0.7). v0.8 은 기획 v0.8.1 29절(문 보상 효과·문 갈래·보상 자리·시간 효과 이어짐·계단 보상과 계단 저장·거울판·`--start-at` 상한·방 이벤트 자리)을 받아 계약 갱신 묶음 **WP1f** 로 모았다.

## 제안과 다르게 반영한 것

- **#15** 안 1·안 2 대신 기획 v0.8.3 2.4 가 같은 때 정한 규칙(시작 문이 들어온 문일 때만 바꾸고, 그 이벤트 안에서 들어온 문 ↔ 맞은편만 맞바꿈)을 따랐다 — 안 1 과 뜻이 같고, 게임 규칙은 기획서가 정한다. 행진의 목표 문 판단에는 "시작 문을 바꿨는가" 가 필요해 `RemapMarch(at, toward)` 를 더했다.
- **#3·#16** 두 안을 다 썼다. 메뉴(문 단계)는 ⓐ `Suspend` 가 Core 안에서 계단 문 `Exit` 명령으로 한 틱 돌린 뒤 정산(앱이 멈춤 중에 틱을 따로 돌리지 않음), 자동 조작은 ⓑ 계단 문 틈을 밟아 `Phase == Exit` 가 된 틱에 `Advance` 대신 부른다. 비교하는 "끊지 않은 판" 은 같은 틱에 계단 문으로 나간 판이다.
- **#4·#18** `Carry` 는 "`CanSuspend` 거짓" 대신 nullable — WP3 없는 Core 시험도 끊고 잇기를 돌려야 해서다. 대신 `IHeroCarry` 등록 여부와 null 여부가 다르면 불일치. Core 는 시간 효과 ID 목록을 모르므로 WP3 만 아는 뜻은 `IHeroCarry.Validate` 로 넘겼다. 필드 규칙은 제안의 예(모양이 바뀌면 `Format` 올려 버림)를 골랐고, 올리기를 잊지 않게 **모양 지문 시험**을 더했다.
- **#5·#20** 시간 제한은 "입력 픽셀 비례" 가 아니라 "진행 없음"(묶음의 출력 파일 수가 2분 동안 안 늚)으로 — GPU 속도를 몰라도 서고, 큰 묶음이 정상적으로 오래 걸리는 것과 멈춘 것을 가른다. 묶음 크기(입력 16MP)·2분은 첫 값이고 WP0 이 이 PC 에서 잰다.
- **#12·#24** 표에서 `output_scale` 을 빼지 않고 "2 만 받음" 으로 남겼다 — 기획 19.6·열린 질문 41 이 이 값을 표 한 줄로 말하고 있고, 4배로 갈 때 바꿀 곳(표 읽기 허용 값·메타 검사)이 한 곳에 모인다.
- **#2·#17** "공개 필드만" 을 강제하는 대신 규칙을 "공개 읽기·쓰기 멤버(필드 또는 get·set 속성), 값 형식·그 배열" 로 넓혔다 — 지금 `RunStats`·`FairnessCounters` 멤버가 모두 get·set 속성이라 필드로 바꾸면 커밋된 코드를 다 고쳐야 하고, 손실의 원인은 속성이 아니라 get-only 였다. 반사 시험이 get-only·허용 밖 형을 실패시킨다.

  `RunStats.WeaponSlotCount = 4`·`public float[] DamageByWeapon { get; } = new float[WeaponSlotCount]`(Progression.cs 75·83), 다른 멤버는 get·set 속성(#2). `FairnessCounters` 는 `sealed`(partial 아님), 멤버는 get·set 속성(#13 ③).
  `Hero.Reset()` 인자 없음(#13 ①). `RoomFlow.cs` 193(`DoorsOpened` 신호 자리)과 `World.cs` 87(주인공 시작 방향)이 `rules.RewardAnchor` 를 읽는다 — v0.8 표는 114(보상 자리)만 바꿨다(#13 ②).
- 확대 프로그램 zip(SHA-256 `abc02804…` — 설계 1.4 값과 같음)을 새 스크래치 빈 폴더에 풀어 **실행하지 않고** 바이트만 읽음: PE 가져오기 = `vulkan-1.dll`·`ole32.dll`·`KERNEL32.dll`·`OLEAUT32.dll`·`VCOMP140.DLL`(지연 가져오기 없음 — #19 그대로).
  도움말 문자열: `-g gpu-id`·`-t tile-size`·`-m model-path`(기본 `models`)·`-j load:proc:save` — GPU 목록만 내는 옵션 없음(#14), 모델 기본 경로가 상대 경로(#21 의 `-m`).
- 기획서는 같은 때 v0.8.3 으로 고쳐지는 중이었다 — 2.4 "바꾸기는 한쪽만"·2.5 "저장하는 순간 = 그 틱에 계단으로 나간 것"·15절 "끊는 틱"·10.1 세로 창살 셋 중 하나·19.6 그림자 굽기를 읽고 설계 문장을 그 뜻에 맞췄다.
- 실행·빌드는 하지 않았다(문서 갱신만). 원본·게임 창을 쓰지 않았다.

## 기획서에 넘기는 것 (기획 담당 v0.8.3 — 설계는 이 뜻으로 적었다)

### #3 (중간, 설계) `Suspend` 의 틱

- 자리: 3.6 결정 4 `CanSuspend`·`Suspend`, 11.1 WP1f 완료 기준 "끊고 잇기"

### #4 (중간, 설계) 이어 하기 불일치·`Carry` null·R41
