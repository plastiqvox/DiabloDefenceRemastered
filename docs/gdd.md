## 1. 개요

**한 줄 소개**: 무너진 성당 안뜰에서 몰려오는 언데드 무리를 피해 다니며, 저절로 나가는 마법을 키워 해골 왕을 쓰러뜨리는 생존 액션.

**기둥(지킬 것)**

1. **움직임이 곧 조작**: 공격 버튼이 없다. 어디로 걷느냐(보석 줍기, 포위 뚫기, 장애물 활용)가 실력이다.
2. **고르는 재미**: 레벨업마다 3개 중 1개. 무기 4칸·패시브 4칸 제한 때문에 빌드가 갈린다.
3. **디아블로 1 분위기**: 어두운 안뜰, 주인공 둘레만 밝은 빛, 화로 불빛, 언데드, 파란 이름 정예와 금색 이름 우두머리.
4. **데이터로 늘어나는 내용**: 새 적·무기·패시브·스테이지는 정의(데이터) 추가로 늘린다(13절).

**화면 기준**: 세계를 **가상 해상도 960×540 월드 픽셀**로 보여 준다(1:1, 창 크기에 맞춰 확대).
맵 1536×1024 는 화면 약 1.6×1.9 배라 카메라가 주인공을 따라 움직이고 맵 경계에서 멈춘다. (열린 질문 1)

## 2. 핵심 루프·한 판·승패·난이도

### 2.1 핵심 루프

```
걷는다 → 무기가 저절로 나간다 → 적이 죽고 경험치 보석을 떨군다 → 보석을 줍는다
  → 레벨업(시간 멈춤, 3개 중 1개 선택) → 더 강해진다 → 적이 더 많고 세진다 → … → 보스 처치
```

- 바깥 루프(MVP): 스테이지 1 을 깨면 스테이지 2 가 열린다. 최고 기록(생존 시간·처치 수·레벨)이 남는다.
- 바깥 루프(E): 누적 금화로 영구 강화 상점(12.7).

### 2.2 한 판 길이와 승패

| 스테이지 | 일반 구간 | 보스 등장 | 광폭화 | 예상 한 판 |
|---|---|---|---|---|
| 1. 버려진 안뜰 | 0:00~10:00 | 10:00 해골 왕 | 보스 등장 후 3:00 | 11~13분 |
| 2. 피의 성소 | 0:00~12:00 | 12:00 피의 왕 | 보스 등장 후 3:00 | 13~15분 |

- **승리**: 그 스테이지 최종 보스를 처치. 처치 즉시 남은 적이 모두 무너지고(처치 연출, 경험치 없음) 3초 뒤 결과 화면.
- **패배**: 주인공 체력 0 → `HeroDie` 재생(23프레임) → 2초 뒤 결과 화면. 일시정지 메뉴의 "포기"도 패배 처리.
- **광폭화**: 보스 등장 3분 뒤에도 살아 있으면 보스 피해 ×2, 이동 ×1.3, 화면 가장자리 붉은 맥동. 시간 제한 대신 압박만 준다.
- 각 스테이지는 **Lv1, 시작 무기(매직 미사일)만 들고** 새로 시작한다(스테이지 간 이어지지 않음).

### 2.3 난이도 상승 곡선 (공통 규칙)

시간이 흐르면 세 가지가 함께 오른다: **동시 최대 수·초당 생성 수**(구간표), **적 체력·피해 배율**(식), **종류 구성**(구간표 가중치).

| 항목 | 스테이지 1 | 스테이지 2 |
|---|---|---|
| 적 체력 배율 (t = 경과 분, 실수) | 1 + 0.08 × t | 1.6 + 0.10 × t |
| 적 피해 배율 | 1 + 0.03 × t | 1.3 + 0.04 × t |
| 정예 무리 확률(60초마다 판정, 2:00부터) | 25% | 40% |

- 배율은 **생성 순간**의 경과 분으로 정해진다(살아 있는 적은 그대로).
- **시간 배율 대상**: 일반 적·정예·우두머리·이벤트로 나온 적·보스/중간 보스가 부른 적(부른 순간 기준). 그 적이 만든 투사체·폭발·장판(자폭, 불타는 접두사 폭발, 역병 웅덩이 등) 피해도 그 적의 피해 배율을 따른다.
- **시간 배율 제외**: 중간 보스·보스 **본체**의 체력과 피해(패턴의 투사체·장판·폭발 포함) — 표의 값 그대로.
- 배율이 쌓이는 식(적의 최종 수치)은 4.2 에 한 곳으로 적는다.
- 구간별 표는 스테이지별로 10절에 있다.

**동시 수와 전체 상한**

- 일반 생성은 그 구간의 **동시 최대** 안에서만 한다(아래 2.4 누적기).
- **전체 상한 300**(성능 상한)은 살아 있는 적 전부를 센다. 넘칠 때 우선순위: 일반 생성 → 이벤트 → 분열·보스/중간 보스 소환 순으로 먼저 막힌다.
  - 이벤트 생성이 300 을 넘게 되면 **화면 밖에서 주인공과 가장 먼 일반 적**(정예·우두머리·대장·중간 보스·보스 제외)부터 조용히 지워(경험치 없음) 자리를 낸다. 지울 적이 없으면 들어갈 만큼만 낸다.
  - 분열(`split_on_death`)과 보스·중간 보스 소환은 300 을 넘어도 낸다. 단 **절대 상한 360** 을 넘지 않으며, 그때도 위와 같이 먼 일반 적을 먼저 지운다.
    그래서 패턴(시체 부르기·해골 소환)이 빈손이 되지 않는다.

### 2.4 스폰 규칙

- **위치**: **카메라 시야 사각형 바깥 40~200px 띠** 안에서 무작위(사방에서 고르게, 화면 바로 밖에서 나온다).
  조건: 맵 안, 걸을 수 있는 곳, 맵 경계와 장애물에서 **(그 유닛 몸 반경 + 4)px 이상** 떨어진 곳.
  후보를 12번 뽑아도 없으면 **입구** 중 주인공에서 가장 먼 곳으로 들어온다(아래 입장 규칙).
- **입구**: 맵 정의(10.1, `map` 정의 13.1)의 입구 목록. 입구마다 **바깥 시작점**(맵 밖)과 **진입점**(맵 안, 경계·장애물에서 60px 이상)이 있다.
  이벤트 무리·중간 보스·보스, 그리고 위치 후보가 없는 일반 생성은 입구로 들어온다.
- **입장 규칙**: 바깥 시작점에서 생겨 진입점까지 **직선으로** 걷는다. 이 동안 맵 경계·장애물·분리(steering) 충돌을 무시하고,
  피해를 주지도 받지도 않으며, 공격·패턴을 쓰지 않는다. 진입점에 닿으면 보통 행동을 시작한다. (원작 보스가 맵 밖 (-100,-100) 에서 계단으로 들어오던 느낌)
  카메라는 맵 경계에서 멈추므로 맵 밖 구간은 보이지 않는다.
- **등장 연출**(입구가 아닌 자리에서 생길 때): 0.4초 동안 투명→불투명, 발밑에 어두운 원(알파 0.4→0). 등장 중에는 피해를 주지도 받지도 않는다.
- **일반 생성 누적기**: 구간표의 "초당 생성"은 **마리 수**다. 매 틱 누적기에 `초당 생성 × dt` 를 더하고,
  미리 뽑아 둔 무리 크기 n(1~3, 균등) 이상이 되면 n 마리를 같은 자리 둘레(반경 40)에 한 무리로 내고 누적기에서 n 을 뺀다.
  살아 있는 적이 그 구간 동시 최대 이상이면 누적기는 **3 에서 멈춘다**(밀린 것은 버린다 — 자리가 나도 한꺼번에 쏟아지지 않는다).
- 난수는 모두 실행 씨앗(`--seed`)에서 나온다(스폰·드롭·레벨업 선택 재현 가능).

## 4. 주인공(마법사)과 성장

### 4.1 기본 능력치

| 능력치 (키) | 기본값 | 비고 |
|---|---|---|
| 최대 체력 `max_hp` | 100 | 원작 그대로 |
| 이동 속도 `move_speed` | 95 px/s | 원작 83 보다 조금 빠르게. 걷기 애니메이션 재생 속도는 실제 속도/83 에 비례 |
| 방어 `armor` | 0 | 받는 피해에서 그대로 뺀다(최소 1) |
| 체력 재생 `regen` | 0 /s | |
| 피해 증가 `damage_pct` | 0% | |
| 쿨다운 감소 `cooldown_pct` | 0% | 최대 60% |
| 범위 증가 `area_pct` | 0% | 폭발·장판·회전 반경, 그림 크기 |
| 투사체 추가 `projectile_count` | 0 | |
| 지속 증가 `duration_pct` | 0% | |
| 치명 확률 `crit_chance` | 0% | 치명 피해 ×2.0 |
| 획득 반경 `pickup_radius` | 60 px | 이 안의 보석·금화가 날아온다 |
| 이동 속도 % `move_pct` | 0% | 최종 이동 = `move_speed × (1 + move_pct)` |
| 획득 반경 % `pickup_pct` | 0% | 최종 획득 반경 = `pickup_radius × (1 + pickup_pct)` |
| 받는 넉백 % `knockback_taken_pct` | 0% | 주인공이 받는 넉백 거리 × (1 + 값). 음수로 쌓는다(돌 피부 −10%/Lv), 하한 −0.8 |
| 금화 % `gold_pct` | 0% | 줍는 금화 × (1 + 값), 반올림 |
| 몸 반경 | 14 px | 충돌 원 |
| 피격 무적 | 0.25 s | 맞은 뒤 이 시간 동안 피해 무시(떼에 둘러싸였을 때 한 번에 녹는 것 방지) |

- **능력치 키 적용 규칙**: 패시브·영구 강화·지속 효과는 모두 위 키에 값을 **더한다**. `_pct` 키는 같은 키끼리 더한 뒤 "기본값 × (1 + Σ%)" 로 한 번 곱한다.
  절댓값 키(`max_hp`, `armor`, `regen`, `projectile_count` 등)는 그대로 더한다.

**주인공과 적의 몸 충돌**

- 적은 주인공을 **단단한 원**으로 취급한다(주인공 질량 무한). 겹치면 적만 밀려난다 → 적이 주인공을 밀어 옮기지 못한다.
- 주인공은 일반 적·정예에게 **막히지 않는다**. 대신 몸이 닿아 있는 적이 3마리 이상이면 이동 속도 ×0.6(무리에 끼여 끈적임).
  → 포위는 "갇힘"이 아니라 "느려지며 맞는 시간"이 된다. 포위 뚫기 = 얇은 쪽을 골라 빠르게 빠져나가기.
- **중간 보스·보스**(그리고 반경 20 이상 적)는 주인공에게도 단단하다: 겹치면 주인공 쪽이 밀린다(지나갈 수 없다).
- 넉백(강타·내려치기)은 위 규칙과 별개로 주인공을 민다. 장애물·맵 경계에서 멈춘다.

### 4.2 피해 계산

- 주는 피해 = `round(무기 피해 × (1 + damage_pct)) × (치명이면 2) − 적 방어`, 최소 1.
- **적의 최종 피해**(한 번 공격·투사체·폭발·장판 틱 모두 같은 식):

  `적 피해 = round(기본 피해 × 시간 피해 배율 × 등급 배율 × (1 + Σ 버프%) × 광폭화)`

  - 기본 피해: 8.2 표 / 패턴 표의 값. 시간 피해 배율: 2.3(제외 대상은 1).
  - 등급 배율: 일반 1, 정예 1.4, 우두머리 1.6 (곱한다).
  - 버프%: 지휘 오라 +25%, 전투 함성 +30% 처럼 **잠깐 붙는 강화는 더한다**(오라 + 함성 = ×1.55). 같은 이름의 버프는 겹치지 않고 하나만(가장 큰 값).
  - 광폭화: 보스 본체만 ×2 (2.2), 나머지 1.
  - 반올림은 마지막에 한 번.
- **적의 최종 체력** = `round(기본 HP × 시간 체력 배율 × 등급 배율(정예 3.5 / 우두머리 8) × (1 + 접두사 HP%))`. 생성 순간에 정한다.
- 받는 피해 = `적 피해 − armor`, 최소 1.
- 최종 쿨다운 = 무기 쿨다운 × (1 − cooldown_pct), cooldown_pct 상한 0.6.

### 4.3 경험치와 레벨

- 적은 죽을 때 **자기 경험치 값을 가진 보석 1개**를 떨군다(11.1). 보석을 주우면 그 값만큼 경험치.
- 레벨 L 에서 L+1 로 가는 필요 경험치:

| 레벨 구간 | 필요 경험치 |
|---|---|
| L = 1 | 5 |
| 2 ≤ L ≤ 19 | 5 + 10 × (L − 1) (2→3 은 15, 19→20 은 185) |
| 20 ≤ L ≤ 39 | 185 + 13 × (L − 19) |
| L ≥ 40 | 445 + 16 × (L − 39) |

- 기대치: 스테이지 1 끝(10분) 무렵 Lv 22~26. 레벨 상한 없음.
- 한 번에 여러 레벨이 오르면 선택 창을 레벨 수만큼 연달아 띄운다.

### 4.4 레벨업 선택

- 시간이 멈추고 **카드 3장**을 보여 준다. 카드: 아이콘, 이름, `새로 얻음` 또는 `Lv 3 → 4`, 이번 레벨에서 바뀌는 수치 한두 줄.
- **슬롯**: 무기 4칸, 패시브 4칸(MVP). 칸이 차면 새 무기/패시브는 후보에서 빠진다.
- **후보 가중치**: 가진 무기 강화 100, 가진 패시브 강화 100, 새 무기 70(칸 남을 때), 새 패시브 70(칸 남을 때). 만렙은 빠진다. 3장은 서로 다르다.
- **초반 보장**: Lv 2 가 되었을 때, Lv 3 가 되었을 때 뜨는 선택에는 새 무기 카드가 최소 1장(무기 칸이 남아 있으면).
- 후보가 3개 미만이면 채움 카드: `체력 물약`(체력 30 회복), `금화 주머니`(금화 25). 후보 + 채움이 3장이 안 되면 **3장보다 적게** 보여 준다(모든 것이 만렙이면 2장).
- **재추첨**: 한 판에 3회(MVP). 3장을 새로 뽑는다(직전 3장 제외 아님).
- **건너뛰기**: 무제한, 체력 10 회복.
- **봉인**(후보에서 영구 제외): E.
- 진화는 레벨업 카드로 나오지 않고 **정예 상자**에서만 나온다(7절).

## 5. 무기 (자동 발동)

### 5.1 공통 규칙

- 무기는 각자 쿨다운이 돌고, 다 되면 저절로 발동한다. 최대 Lv 8.
- **조준 규칙**(무기 정의의 `targeting` = ID + 반경):

  | ID | 규칙 | 대상이 없을 때 |
  |---|---|---|
  | `nearest` | 반경(기본 450) 안 가장 가까운 적. 여러 발이면 가까운 순으로 서로 다른 적(적이 발 수보다 적으면 다시 처음부터) | 바라보는 방향으로 쏜다. 유도형(`homing`)은 쏘지 않고 대기 |
  | `random_in_radius` | 반경 안 무작위 적 | 바라보는 방향 |
  | `facing` | 바라보는 방향(3절) | — |
  | `densest` | 반경 안 64px 격자 칸 중 적이 가장 많은 칸 가운데 | 주인공 둘레 무작위 |
  | `none` | 조준 없음(주인공 기준) | — |

- 같은 적을 같은 무기가 연달아 때리는 간격(**적별 타격 간격**)이 무기마다 있다(회전·장판처럼 머무는 무기).
- 투사체는 `blocks_projectiles` 인 장애물(10.2 표)에 닿으면 사라진다. 낮은 장애물(덤불·쓰러진 기둥·석관 등)은 넘어간다. 회전 구체·장판은 장애물을 무시한다.
  → 장애물 위를 지나는 망령은 직선·유도 투사체로는 못 맞힐 수 있다(회전·장판·폭발 범위로는 맞는다). 의도된 특성이다.
- 투사체의 그림·반경(맞음 판정)·속도·유도·수명은 **투사체 정의**(13.1 `projectile`, 목록 13.7)에 있다. 무기는 투사체 ID 를 참조하고, 레벨 표 값(속도 등)이 있으면 그것이 덮어쓴다.
- **주인공 쪽 투사체는 가산(additive) 발광을 한 겹 더 그린다**, 적 투사체에는 **붉은 테 빛**을 그린다 — 둘을 한눈에 구별하기 위해.
- 서 있을 때 무기가 발동하면 주인공이 `HeroCasting`(12프레임, 0.72s)을 재생한다. **이미 재생 중이면 다시 시작하지 않는다.** 움직이기 시작하면 바로 걷기로 바뀐다.
- 그림 사용: 아래 "그림" 열은 시트·색조(RGB 곱하기)·크기 배율·혼합. 색조 `원색` = 흰색(255,255,255).
- 무기 아이콘은 기존 아이콘에 색조를 주거나 이펙트 프레임 한 장을 48×48 칸에 맞춰 그린다(5.9).

## 7. 진화 (무기 + 패시브)

- 조건: 무기 **Lv 8** + 짝 패시브를 **가지고 있음**(레벨 무관).
- 조건이 맞은 상태에서 **정예 상자**(11.1)를 열면 진화한다. 조건 맞는 무기가 여럿이면 하나만(먼저 만렙이 된 것).
- 진화 무기는 원래 무기 칸을 그대로 쓴다. 레벨 개념 없음.
- 정의 모양: 진화 무기 = `base_weapon`(재료 무기 ID) + 덮어쓸 수치(Lv8 값 위에) + 바꿀 투사체·이펙트 ID + 추가 효과(예: `inferno` 의 `on_explode: 장판 남기기(fx_inferno_pool, 틱 10, 반경 60, 2s)`).

## 8. 몬스터

### 8.1 공통 규칙

- **그림 변형 방법**: 기존 시트 5벌에 **색조**(RGB 곱하기), **크기 배율**, **알파**, **발광**(같은 프레임을 가산 혼합으로 한 번 더, 지정 색·알파)을 준다.
  곱하기 색조는 어둡게만 만들 수 있으므로 밝은 느낌(불타는, 금색)은 발광을 같이 쓴다.
  - 유닛 시트 발밑에는 그림자가 그림으로 구워져 있다. 색조·발광·번쩍임·알파가 **그림자에도 같이 걸린다(허용 — 버그 아님)**.
  - 해골 원본 색이 연분홍이라 금색·주황 색조는 기대와 다를 수 있다. 첫 구현 때 색조 미리보기 화면(개발용)으로 확인하고 값을 고친다.
- **위치 기준점**: 유닛 위치 = **발 위치**. 시트마다 프레임 안 발 픽셀(`origin`, 13.1 `sprite`)을 두고 그 점을 위치에 맞춰 그린다.
  충돌 원·y 정렬·그림자·발밑 원(오라·아군 표시)은 모두 이 점 기준. 크기 배율도 이 점을 중심으로 건다.
- **몸 반경** = 기본 반경 × 크기 배율. 무리끼리는 분리(steering)로 겹치지 않게 밀어낸다. 주인공과의 몸 충돌은 4.1.
- **길찾기**: 일반 적과 **정예·우두머리는 플로우 필드**(무리로 함께 움직이고 몸 크기가 일반 적과 비슷하기 때문 — brief 2절 기본안 "정예는 A*" 와 다르게 정함).
  중간 보스·보스·아군은 개별 길찾기(A*). `wraith`(장애물 통과)는 직선.
- **근접 공격**: 사거리(몸 반경 합 + 6px) 안에 들면 멈춰서 공격 애니메이션 재생. **타격 프레임**에 아직 사거리 + 10px 안이면 피해. 공격 쿨 1.0s(종류별 다름). → 옆으로 빠지면 피할 수 있다.
- **원거리**: 장애물에 가리지 않을 때만 쏜다. 적 투사체는 `blocks_projectiles` 장애물에 막힌다.
  원거리 적(`goatman_archer`, `goatman_shaman`, `skeleton_mage`)의 "피해" 열은 **투사체 피해**이며 근접 공격은 없다(몸이 닿아도 피해 없음).
- **애니메이션**: 프레임 60ms. 걷기 재생 속도는 실제 속도 / 기본 속도에 비례.
- **죽음**: `…Die` 시트 재생 → 마지막 프레임으로 시체 2초 → 0.5초 동안 투명해짐. 시체 상한 150(넘으면 오래된 것부터 지움).
  `Swordman` 계열은 죽는 그림이 없으므로 **마지막 공격 프레임에서 멈춰 0.6초 동안 붉게 변하며 투명해짐** + `MagicMissileExplosion` 색조 (200,40,40) ×0.6.
- **넉백 저항** 0~1: 받는 넉백 거리 × (1 − 저항). 1 이면 면역.
- 태그: 종류 묶음. 오라·소환·이벤트가 태그로 대상을 고른다. 각 적의 태그는 8.2 표 "태그" 열.
  쓰는 태그: `skeleton`, `zombie`, `goatman`, `knight`, `undead`, `demon`, `spirit`, `fire`, `ranged`, `leader`, `boss`.

## 9. 정예·중간 보스·보스

### 9.1 정예 (챔피언, 파란 이름)

- **종류 고르기**: 확률 판정(2.3)으로 생기는 정예 무리는 **현재 생성 구간의 구성 가중치**에서 종류를 뽑는다(`skeleton_captain`·`corpse_spawn` 제외).
  시간표 이벤트의 정예 무리는 종류를 직접 지정한다.
- **정예 무리**: 같은 종류 3~5마리, 모두 정예, 같은 접두사 1개. 입구 또는 스폰 위치 한 곳에서 함께 등장. 등장 때 화면 위에 "정예 무리가 나타났다" 1.5s.
- 생성: 2.3 의 확률 판정(60초마다) 또는 시간표 이벤트. 길찾기는 플로우 필드(8.1).
- 배율: HP ×3.5, 피해 ×1.4, 이동 ×1.1, 경험치 ×4, 크기 ×1.15, 넉백 저항 +0.3.
- 표시: 이름 파란 글씨(머리 위, 맞았을 때만 3초 보임 — 무리가 많으면 시끄럽기 때문), 몸에 파란 발광 (90,140,255) α 0.25~0.45 맥동(1.2s 주기).
- 드롭: 금화 100%(10~30), 체력 물약 25%, 마력 폭주 15%.

### 9.2 우두머리 (유니크, 금색 이름)

- 정예 무리의 **대장 1마리**로 나올 수 있다(정예 무리 중 30%). 또는 시간표 이벤트.
- 배율: HP ×8, 피해 ×1.6, 이동 ×1.1, 경험치 ×10, 크기 ×1.3, 넉백 저항 0.8, 접두사 **2개**.
- 이름: `<접두사> <종류 이름>` 을 금색으로 늘 표시. 몸에 금색 발광 (255,200,80).
- 드롭: **정예 상자 100%** + 금화 30~60.

### 10.2 장애물 그리기 규칙

새 그림 자원이 없으므로 장애물은 코드로 그린다. 정의 하나(바닥 모양 + 높이 + 종류)에서 그림과 충돌을 함께 만든다.

- **바닥 모양 = 충돌 모양**: 원, 사각형, 다각형.
- **질감**: 맵의 돌 바닥 영역에서 잘라 쓴다. 기본 원본 = 남쪽 돌길 (620,780)~(900,1000). 윗면은 원본 그대로 ×1.1 밝게, 옆면(남쪽을 향한 면)은 ×0.55 어둡게.
- **높이감**: 윗면을 바닥 모양에서 위로 `높이` px 올려 그리고, 그 사이를 옆면으로 채운다. 윗면 가장자리 1px 밝은 선.
- **그림자**: 바닥 모양을 오른쪽 아래로 (높이×0.3, 높이×0.2) 밀어 검정 α0.45, 가장자리를 부드럽게. 유닛보다 먼저 그린다.
- **그리기 순서**: 장애물도 유닛과 함께 **발밑 y**(바닥 모양의 가장 아래 y)로 정렬한다. 키 큰 기둥 뒤로 지나가는 유닛은 가려진다. 가려진 주인공은 **윤곽이 보이게** 한다(반투명 실루엣 등).
- 그림자 흐림·윤곽선을 **어떤 방법으로 만들지**(미리 구운 텍스처, 셰이더 등)는 설계에서 정한다. 기획은 "보이는 결과"만 정한다.
- **조명 반응**: 장애물도 스테이지 주변광 색을 곱한다.
- **배치 덮어쓰기**: 배치 항목은 종류의 기본 `높이` 를 덮어쓸 수 있다(예: `s1_wall_w` 높이 30).
- **투사체 막음**(`blocks_projectiles`): 높이 25 이상인 종류는 막고, 낮은 것은 투사체가 넘어간다(5.1). 아래 표 열.

|---|---|---|---|---|
| `pillar` 기둥 | 원 r 18~22 | 72 | 예 | 윗면 원 둘레에 가는 어두운 고리(깎은 돌 느낌) |
| `broken_pillar` 부서진 기둥 | 원 r 18~22 | 30 | 예 | 윗면 가장자리를 들쭉날쭉(다각형 꼭짓점 ±4px 흔들기) |

  가장 가까운 걸을 수 있는 곳에 놓고, 반경 R/2 까지 줄여도 없으면 그 한 마리는 생략한다.

| 피해 숫자 | 적 머리 위, 0.6s 동안 24px 떠오르며 사라짐. 일반 흰색 14px, 치명 노랑 18px + `!`, 주인공이 받은 피해 빨강. 같은 적에게 0.1s 안에 들어온 피해는 한 숫자로 합침. 화면에 최대 120개(넘으면 오래된 것부터 지움). 설정으로 끔 |
| 맞을 때 번쩍임 | 적: 0.08s **밝게 번쩍임**(하얗게 보일수록 좋다. 방법은 설계에서 정한다 — 셰이더 없이 같은 프레임을 가산으로 덧그리는 방식이면 "밝아짐" 정도로 충분). 주인공: 0.15s 붉게 + 피격 무적 동안 반투명 깜빡임 |
| 넉백 | 무기별 거리(px)를 0.12s 에 걸쳐 밀어냄. 넉백 저항 적용 |
| 화면 흔들림 | 주인공 피격 2px 0.12s, 파이어볼 폭발 1px 0.08s, 보스 내려치기 3px 0.2s, 보스 등장 4px 0.5s, 보스 처치 6px 0.4s. 동시에 여러 개면 가장 센 것. 설정으로 끔 |
| 처치 연출 | 죽음 애니메이션 + 작은 보석이 위로 튀었다 떨어짐(0.25s). 정예 처치: `MagicMissileExplosion` 파란 색조 + 흔들림 1px |
| 히트 스톱 | 중간 보스·우두머리 처치 0.08s 멈춤, 보스 처치 0.6s 슬로모션 |
| 레벨업 | 금색 빛 기둥 + 주변 적 80px 밀어냄(선택 창이 닫힌 직후) |
| 위험 예고 | 적의 돌진·폭발·장판·보스 패턴은 모두 붉은 예고(선 또는 원)를 먼저 보여 준다. 예고 없이 큰 피해를 주지 않는다 |
| 소리 | 소리 자원이 없다 → MVP 무음 (열린 질문 2) |

## 13. 확장 원칙 (데이터 정의)

기획 쪽 원칙: **"새 내용 = 정의 한 개 추가"**. 새 행동이 정말 필요할 때만 코드에 행동 부품을 하나 더하고, 그 뒤로는 그 부품을 정의에서 고른다.
정의를 어떤 형식(JSON 파일 / C# 정의 목록)으로 둘지는 설계에서 정한다(열린 질문 4). 기획은 아래 항목과 규칙을 정한다.

### 13.1 정의 종류와 항목

| 정의 | 주요 항목 |
|---|---|
| 그림 `sprite` | 시트 파일, **시트 크기(px)**, 프레임 크기, 방향 수, 프레임 수, 투명색, **발 기준점 `origin`**(프레임 안 픽셀, 8.1), 남는 픽셀 허용(예: `FireBall` 폭 1540 → 4px 버림) |
| 이펙트 `effect` | ID, 시트, 프레임 범위, 반복 여부, 프레임 시간, 색조, 크기(또는 "반경에 맞춤"), 알파, 혼합(일반/가산), 빛(색·반경·시간), 화면 흔들림(px·시간). 예고 표시(코드 그림 원·선)도 이펙트 ID 로 둔다 |

| 맵 `map` | ID, 그림, 미니맵, 크기, 고정 충돌 모양(`collision_only`, 투사체 막음 여부), 입구 목록(ID·바깥 시작점·진입점), 주인공 시작 위치·방향, 기준점(ID·좌표), 장애물 질감 원본 영역 |

| 무기 `weapon` | ID, 이름, 아이콘(시트·프레임·색조), 발사 패턴 ID, **`targeting`**(ID + 반경, 5.1), 투사체 ID 또는 이펙트 ID, **`base`**(레벨 무관 고정값: 회전율·수명·사거리·넉백·틱 간격 등), 레벨 표(열 이름 = 발사 패턴이 읽는 키, 13.2), 적별 타격 간격 |
| 진화 무기 | `weapon` 과 같은 모양 + `base_weapon`(재료 무기 ID), 덮어쓸 수치, 추가 효과(예: `on_explode`) (7절) |
| 패시브 `passive` | ID, 이름, 아이콘(+색조), 최대 레벨, 레벨당 `stat 키 + 값` 목록(4.1), `on_acquire` 효과(선택) |

| 장애물 종류 `obstacle_kind` | ID, 높이, 꾸밈 방식, 빛 내는지(색·반경), `blocks_projectiles`, `parts`(충돌 모양 여러 개 + 그림 전용 부분, 아치), 그리지 않음(`collision_only`) |
| 스테이지 `stage` | ID, 이름, **맵 ID**, 장애물 배치 목록(종류 ID + 모양 + 좌표 또는 기준점 ID + `height` 덮어쓰기), 조명(주변광·어둠·빛 목록), 체력/피해 배율 식 계수, 정예 확률, 생성 구간 표, 이벤트 목록(위치는 `entry:<입구 ID>`), 보스 ID, 해금 조건 |

### 13.2 무기 발사 패턴 (코드 부품)

`homing`(유도), `straight_explode`(직선 + 폭발), `orbit`(회전), `ricochet`(튕김), `fan`(부채꼴 관통), `ground_pool`(장판).
E: `nova`(퍼지는 고리), `sky_drop`(낙하), `chain`(즉시 연쇄), `summon`(아군).
→ 같은 패턴에 그림·색조·수치만 바꿔 새 무기를 만든다(예: `frost_bolt` = `straight_explode` 에 둔화 효과 추가).

**패턴이 읽는 레벨 표 키와 주인공 능력치가 붙는 자리**

| 패턴 | 레벨 표 키 | `projectile_count` 가 더해지는 키 | `area_pct` 가 곱해지는 키 | `duration_pct` 가 곱해지는 키 |
|---|---|---|---|---|
| `homing` | damage, cooldown, count, pierce, speed | count | (그림 크기만) | — |
| `straight_explode` | damage, radius, cooldown, count | count | radius(+ 폭발 그림) | — |
| `orbit` | damage, count, orbit_radius, duration, cooldown | count | orbit_radius(+ 구체 그림) | duration(상시는 그대로) |
| `ricochet` | damage, bounces, cooldown, count | count | (그림 크기만) | — |
| `fan` | damage, count, pierce, cooldown, spread | count(퍼짐각은 그대로, 간격이 좁아짐) | (그림 크기만) | — |
| `ground_pool` | tick_damage, radius, duration, count, cooldown, slow_pct | count | radius | duration |

모든 패턴에서 `damage`·`tick_damage` 에는 `damage_pct`, `cooldown` 에는 `cooldown_pct` 가 붙는다(4.2).

### 13.3 몬스터 행동 부품 (코드 부품)

**일반 적 행동 부품**: `chase_melee`, `kite`, `shoot_projectile`(투사체 ID 를 받음 — 궁수 화살·주술사 유도탄·해골 마법사 불덩이가 모두 이것), `self_destruct`, `charge`,
`split_on_death`, `ground_hazard`(장판 남기기, `trigger: on_death / cooldown`), `command_aura`, `escort`, `phase`(장애물 통과), `heavy_strike`, `war_cry`.
→ 원거리 부품은 투사체를 정의로 받는다. 예: 해골 마법사 = `kite` + `shoot_projectile(pj_mage_bolt)`, 역병 좀비 = `chase_melee` + `ground_hazard(on_death)`. 코드 추가 없음.

**보스 패턴 틀**(중간 보스·보스): 보스는 행동 부품 대신 패턴 목록과 페이즈 목록을 가진다. 이동은 `movement: astar` 로 주인공을 쫓고, 패턴이 준비되면 쓴다.

- `패턴 = { 조건, 애니메이션, 예고, 동작 부품 + 매개변수 }`
  - 조건: 거리 범위(최소~최대), 쿨, 또는 `HP 문턱 1회`. 여러 패턴이 동시에 준비되면 표의 위쪽이 먼저.
  - 애니메이션: 시트 ID + 동작이 일어나는 트리거 프레임.
  - 예고: 이펙트 ID(`fx_warning_circle`·`fx_warning_line`) + 시간. 0 이면 예고 없음 — 단 큰 피해 패턴은 예고 필수(12.6).
- `페이즈 = { HP 문턱, 바꿀 패턴 목록(교체·추가·제거), 수치 덮어쓰기(속도·쿨·발 수 등), 전환 연출(무적 시간·흔들림·발광) }`
- **보스 동작 부품**:

| 부품 | 매개변수 | 쓰는 곳 |
|---|---|---|
| `melee_slam` | 피해, 넉백, 흔들림, 사거리 | 썩은 거인·기사 대장 강타, 해골 왕 내려치기 |
| `projectile_spread` | 투사체 ID, 발 수, 각도 범위(360 = 사방), 기준 방향(주인공 / 고정), 피해 | 파이어볼 부채, 화염 고리 |
| `telegraphed_blast` | 지점 고르기(주인공 위치 + 둘레 n곳 반경 r), 예고 시간, 폭발 반경, 피해, 이펙트 ID | 불타는 땅 |
| `dash` | 예고 시간, 속도, 시간, 닿을 때 피해 | 돌진 베기(일반 적 `charge` 와 같은 동작을 보스용으로 묶은 것) |
| `summon` | (몬스터 ID, 수) 목록, 배치 반경, 부른 적 동시 상한 | 시체 부르기, 해골·망령 소환, 기사 대장 함성 소환 |
| `ground_hazard` | 이펙트 ID, 반경, 시간, 틱 피해·간격 | 독 웅덩이 |
| `buff_area` | 반경, 대상 태그, 버프 이름·값·시간 | 기사 대장 전투 함성 |

→ 새 보스 = 몬스터 정의 1개(그림 + 패턴·페이즈 목록). 새 동작이 필요할 때만 부품을 하나 더한다.

### 13.4 이벤트 종류

`banner`(문구), `march`(입구에서 무리가 정해진 방향으로 행진, 직진 시간 기본 15s), `ring`(포위 고리, 막힌 자리 처리 10.3), `elite_pack`(정예 무리 — 종류 지정, 우두머리 확률), `miniboss`, `boss`, `escort`(대장 + 호위 수, 기본 8), `screen_shake`, `light_change`(조명 바꾸기).
각 이벤트는 시각 + 종류 + 매개변수. 위치는 `entry:<입구 ID>` 또는 `around_hero`(주인공 둘레).

### 13.5 데이터 검증 규칙 (테스트로 확인)

1. 모든 ID 는 종류 안에서 유일하다. 참조하는 ID(그림, 이펙트, 투사체, 맵, 입구, 기준점, 몬스터, 드롭 표, 진화 재료, 보스)는 모두 존재한다.
2. 무기 레벨 표 길이 = 최대 레벨(8), 패시브는 5. 수치는 레벨이 오를 때 줄어들지 않는다(쿨다운은 늘지 않는다). 레벨 표 열 이름은 그 발사 패턴이 읽는 키(13.2)뿐이다.
3. 생성 구간은 0:00 부터 빈틈·겹침 없이 이어지고, 구성 가중치 합 > 0.
4. 장애물은 맵 안에 있고, 10.1 의 통로 규칙(80px 또는 붙임)을 지킨다.
5. 길 검사는 **몸 반경 등급 14 / 26 / 34 마다 따로** 돈다(장애물을 그 반경만큼 부풀려서).
   - 14: 주인공 시작 위치에서 모든 입구 진입점·주인공이 갈 수 있는 모든 칸까지 길이 있다(갇힌 주머니 없음).
   - 26·34: 모든 입구 진입점에서 원형 바닥 중심까지 길이 있다(좁은 틈은 못 지나가도 되지만 우회로는 있어야 한다).
6. 입구 진입점과 주인공 시작 위치는 맵 경계·장애물에서 (가장 큰 유닛 반경 34 + 4) 이상 떨어져 있다. 바깥 시작점은 맵 밖이다.
7. 그림 크기 검사는 둘로 나눈다.
   - **정의끼리**(항상 실행): `sprite` 의 시트 크기 = 프레임 크기 × 방향 수/프레임 수(남는 픽셀 허용 표시가 있으면 그만큼 허용). 몬스터 그림 묶음이 가리키는 시트가 모두 있다.
   - **실제 PNG**(그림이 있을 때만): PNG 크기 = 정의의 시트 크기. `Assets/` 가 비어 있으면(클론 직후·CI) **건너뜀으로 표시**한다(실패 아님).
8. 진화 재료 무기의 최대 레벨이 존재하고, 재료 패시브가 존재한다.
9. 패시브의 `stat 키` 는 4.1 표에 있는 키뿐이다.

### 13.6 새 내용 추가 예시

- **새 적 "해골 마법사"**(MVP 에 실제로 넣음): 몬스터 정의 1개(Skeleton 그림, 색조, 수치, `kite` + `shoot_projectile(pj_mage_bolt)`) + 투사체 정의 1개 + 스테이지 생성 구간 가중치에 이름 추가. 끝.
- **새 적 "역병 좀비"**(MVP 에 실제로 넣음): 몬스터 정의 1개(`chase_melee` + `ground_hazard(on_death, fx_poison_pool)`) + 가중치. 끝.
- **새 무기 "서리 화살"**: 무기 정의 1개(`straight_explode` 패턴, 투사체 정의 1개 — FireBall 하늘색, 레벨 표) + 둔화 효과가 없으면 효과 부품 1개 코드 추가.
- **새 마법 이펙트**: 이펙트 정의 1개(시트·프레임·색조·빛). 무기·적·보스 패턴·접두사가 ID 로 가져다 쓴다.
- **새 스테이지**: 스테이지 정의 1개(맵 ID·추가 장애물·조명·시간표·보스). 새 맵이면 맵 정의 1개를 더한다.

### 13.7 MVP 이펙트·투사체 목록

참조하는 쪽(무기·적·패턴)은 **색조·크기만 덮어쓸 수 있다**. 그래서 같은 폭발 그림을 색만 바꿔 여러 곳에서 쓴다(파이어볼·자폭·불타는 접두사·불타는 땅·연옥불 = 모두 `fx_fire_explosion`).

**이펙트 `effect`**

| ID | 시트·프레임 | 반복 | 색조 / 크기 / 혼합 | 빛·흔들림 | 쓰는 곳 |

## 14. MVP 범위와 이후 확장

### 14.1 MVP (세 단계로 나눠 만든다)

MVP 의 **내용**은 아래 표 전부다. 한 번에 만들면 첫 실행까지 길고 리뷰 단위가 너무 커서, **순서**를 세 단계로 나눈다.
각 단계 끝에 실행 가능한 게임이 있고, 그 단계에서 리뷰·검증한다. 사용자 요구 8(몬스터 늘리기)을 위해 1단계부터 몬스터 5종을 넣는다.

| 단계 | 내용 | 끝났을 때 되는 것 |
|---|---|---|
| **1. 세로 조각** | 스테이지 1 맵·고정 충돌·장애물·조명, 입구·입장 규칙, 매직 미사일·파이어볼·비전 구체, 패시브 3(활력·마력 증폭·질주), 해골·좀비·궁수·불타는 해골·굶주린 시체, 경험치·레벨업·결과 화면, 13절 정의 구조(이펙트·투사체·맵 포함)와 검증 규칙, `--autoplay`·`--capture`·`--seed`·15절 개발 옵션 | 스테이지 1 을 10분 동안 돌 수 있다(보스 없이 시간 끝 = 결과) |
| **2. 스테이지 1 완성** | 나머지 무기 3·패시브 3, 시체 덩어리·해골 대장·**해골 마법사**, 정예·우두머리·접두사 3, 썩은 거인, 해골 왕, 정예 상자·진화 2, 타이틀·스테이지 선택·일시정지·설정·저장, HUD 전부·미니맵 | 스테이지 1 을 처음부터 보스 처치까지 |

### 14.2 이후 확장 (우선순위 순)

1. 소리(효과음·음악) — 자원 확보가 먼저.
2. 무기 4종(마나 파동, 유성, 서리 화살, 연쇄 번개), 진화 나머지 4개.
3. 패시브 5종(재생, 다중 시전, 확산, 지속, 탐욕), 봉인.
4. 아군 수호 검사, 스테이지 3 "망자의 밤"과 구출 이벤트.
5. 확장 몬스터 4종(8.4), 접두사 3종(지휘하는, 유령 같은, 흡혈의).
6. 영구 강화 상점(금화 사용), 업적·해금 무기.
7. 게임패드, 주인공 추가(검사를 플레이어 캐릭터로 — `Swordman` 시트), 정화 두루마리 등 새 그림이 필요한 것.

## 15. 검증 지원 — 자동 조작 규칙 (`--autoplay`)

검증 담당이 사용자 입력 없이 한 판을 돌려 보기 위한 규칙. 같은 `--seed` 면 같은 결과가 나와야 한다.

- 이동: 반경 200 안 적들에게서 멀어지는 방향(거리 역수 가중 합) + 반경 300 안 가장 가까운 보석 쪽(가중 0.6)을 더한 방향. 장애물에 막히면 옆으로 미끄러짐.
- 레벨업: 우선순위 — 진화 재료 무기 강화 > 가진 무기 강화 > 새 무기 > 가진 패시브 > 새 패시브. 같은 순위면 카드 왼쪽부터. 재추첨·건너뛰기 안 함.
- 정예 상자·물약은 반경 300 안이면 주우러 간다.
- 메뉴: `--stage` 가 없으면 타이틀에서 **새 게임 → 열린 스테이지 중 가장 뒤의 것**을 고른다. 결과 화면에서는 `--quit-after` 가 없으면 **타이틀로**를 고른다.

**개발 실행 옵션**(brief 7절 `--autoplay`·`--capture <png> --capture-at <초>`·`--quit-after <초>`·`--seed` 에 더함)

| 옵션 | 뜻 |
|---|---|
| `--stage <id>` | 타이틀·스테이지 선택을 건너뛰고 그 스테이지를 바로 시작(잠금 무시) |
| `--start-at <mm:ss>` | 그 시각부터 시작. 그 전 이벤트는 건너뛰고(이미 지난 것으로 침), 생성 구간·시간 배율은 그 시각 값. 보스 시각을 주면 바로 보스 등장 |
| `--time-scale <n>` | 화면 한 장마다 고정 틱을 n 번 돌린다(빨리 감기). 같은 `--seed` 면 `--time-scale` 값과 상관없이 결과가 같아야 한다 |
| `--god` | 주인공이 피해를 받지 않는다(넉백은 받음) |
| `--level <n>` | 그 레벨로 시작(레벨업 선택은 하지 않음) |
| `--weapons <id:lv,…>` | 시작 무기와 레벨 지정(예: `magic_missile:8,fireball:5`). 진화 무기 ID 도 받는다 |
| `--passives <id:lv,…>` | 시작 패시브와 레벨 지정 |

- 예: 보스 검증 = `--stage stage_courtyard --start-at 10:00 --god --level 25 --weapons magic_missile:8,fireball:8 --autoplay --capture boss.png --capture-at 20 --quit-after 30`.
